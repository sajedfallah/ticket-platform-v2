# Ticket Platform v2 🎟️

Professional event ticketing platform for concerts, music, festivals and entertainment events.

## Architecture

- Backend: FastAPI + PostgreSQL
- Telegram Bot
- Telegram Mini App
- Admin Dashboard
- Docker deployment

## MVP Features

- Event management
- Ticket types
- Orders
- Manual payment verification
- QR tickets
- Admin dashboard

## Roadmap

Phase 1: Backend foundation
Phase 2: Telegram Bot
Phase 3: Mini App
Phase 4: Organizer marketplace
